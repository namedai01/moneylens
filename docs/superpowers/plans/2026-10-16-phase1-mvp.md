**Architecture:** Supabase (Postgres + RLS + Edge Function `ingest` + RPC) là backend. App Flutter (`app/`, nền từ Phase 0) gửi nguyên văn thông báo qua hàng đợi local → `ingest` với device key → parser TS ở server tạo transaction. Dashboard Flutter dùng chung cho Android + web.

**Tech Stack:** Supabase CLI, Postgres 15 + pgTAP, Deno/TypeScript (Edge Functions), Flutter 3.32: `supabase_flutter`, `flutter_riverpod`, `go_router`, `flutter_secure_storage`, `sqflite`, `workmanager`, `http`, `intl`, `fl_chart`, `device_info_plus`.

**Phụ thuộc:** Phase 0 xong (`docs/spike/2026-10-vcb-notification-findings.md` + fixtures). **Đã chốt (spike 2026-10-16): listener là Kotlin `VcbNotificationListener`.** Task 7 phải chuyển hàng đợi + gửi HTTP + heartbeat sang Kotlin (Room/SQLite + WorkManager, OkHttp/HttpURLConnection); Dart chỉ đọc trạng thái hàng đợi qua MethodChannel `moneylens/listener`. `nextRetryDelay` 🎓 viết bằng Kotlin. Rà lại Task 7 trước khi làm.

## Global Constraints

- Tiền: VND, số nguyên (`bigint` / Dart `int` / TS `number`), không float.
- Múi giờ gom tháng: `Asia/Ho_Chi_Minh` (UTC+07:00, không DST).
- Device key: `'ml_' + 64 ký tự hex`; server chỉ lưu `sha256` hex của **toàn bộ** chuỗi key. Gửi qua header `x-device-key`.
- Đăng ký công khai tắt; user do chủ dự án tạo.
- Mỗi user 1 device `android` active; đăng ký máy mới thu hồi máy cũ. Không áp cho `gmail_script`.
- Parser version hiện tại: `vcb_notif@1`.
- UI tiếng Việt; định dạng tiền `1.500.000 ₫`.
- Chủ dự án được đọc dữ liệu mọi user (không mã hoá client).
- Secrets (service role key, keystore) không commit.

## Review Focus

1. Giao dịch lúc 00:30 ngày 1 (giờ VN) phải thuộc **tháng mới** dù UTC vẫn là tháng trước. → test `month boundary` ở Task 3 và Task 8.
2. Chuỗi tiếng Việt dạng Unicode NFD (dấu tách rời) vẫn parse được như NFC. → test `nfd input` ở Task 4.
3. Cùng giao dịch đến 2 lần với `postedAt` khác nhau (thông báo đăng lại, sau này thêm Gmail) → chỉ 1 transaction nhờ `ref`. → test `same ref different raw` ở Task 5.
4. User bật "Ẩn khỏi thống kê" rồi chủ dự án chạy reparse `--all` → cờ ẩn giữ nguyên. → test `reparse keeps excluded` ở Task 5.

### Task 4: Parser thông báo VCB (TypeScript)

**Files:** Create `supabase/functions/_shared/parser/vcb_notif.ts`; Test `supabase/functions/_shared/parser/vcb_notif_test.ts` (dùng fixtures từ Phase 0 ở `fixtures/vcb_notif/`)

**Interfaces:**
- Produces:

```ts
export const PARSER_VERSION = "vcb_notif@1";
export type ParsedTxn = {
  accountNumber: string; direction: "in" | "out"; amount: number;
  occurredAt: string;            // ISO, offset +07:00, vd "2026-10-16T10:24:27+07:00"
  balanceAfter: number; ref: string | null; description: string;
};
export type ParseResult =
  | { status: "parsed"; txn: ParsedTxn }
  | { status: "ignored" }
  | { status: "failed"; error: string };
export function parseVcbNotification(title: string | null, body: string): ParseResult;
```

Quy tắc:
- Văn bản = `` `${title ?? ""}\n${body}`.normalize("NFC") ``.
- Không chứa `Số dư TK VCB` → `ignored`.
- Có nhưng không khớp regex dưới → `failed` (error mô tả ngắn).

```ts
/Số dư TK VCB (\d+) ([+-])([\d.,]+) VND lúc (\d{2})-(\d{2})-(\d{4}) (\d{2}):(\d{2}):(\d{2})\. Số dư ([\d.,]+) VND\. Ref (.*)$/s
```

- Số tiền: bỏ mọi `,` và `.` rồi `Number`. (Nếu spike thấy có phần thập phân → sửa trước khi làm task này.)
- `Ref`: phần sau `Ref ` = `rest`. Nếu `rest` bắt đầu `MBVCB.` → `ref = "MBVCB." + đoạn tới dấu "." kế tiếp`, `description = phần còn lại sau dấu "." đó`. Ngược lại theo mẫu tiền vào trong `docs/spike/...findings.md` (cập nhật quy tắc tại đây trước khi code); không xác định được → `ref = null`, `description = rest`.

```ts
// _shared/repo.ts
export type Device = { id: string; userId: string; revoked: boolean };
export type RawEventInput = { userId: string; deviceId: string; source: "android_notif" | "gmail";
  packageName: string | null; title: string | null; body: string; postedAt: string; dedupHash: string };
export type RawEventRow = RawEventInput & { id: string };
export interface Repo {
  findDeviceByKeyHash(hash: string): Promise<Device | null>;
  touchDevice(deviceId: string): Promise<void>;
  insertRawEvent(e: RawEventInput): Promise<RawEventRow | null>;          // null = trùng dedup_hash
  ensureAccount(userId: string, bankCode: string, last4: string): Promise<string>; // name mặc định "VCB ****<last4>"
  upsertTransactionForRaw(t: { userId: string; accountId: string; rawEventId: string; source: string } & ParsedTxn)
    : Promise<"inserted" | "updated" | "duplicate">;  // đã có txn cùng raw_event_id → update field parse (KHÔNG đụng excluded); trùng (user,account,ref) → duplicate
  setParseResult(rawId: string, status: "parsed" | "ignored" | "failed", error: string | null, version: string): Promise<void>;
  listRawEvents(filter: "failed" | "all"): Promise<RawEventRow[]>;          // cho reparse
}
export function createSupabaseRepo(url: string, serviceRoleKey: string): Repo;

// _shared/process.ts
export async function sha256Hex(s: string): Promise<string>;
export async function processRawEvent(raw: RawEventRow, repo: Repo): Promise<"parsed" | "ignored" | "failed">;

// ingest/handler.ts
export async function handleIngest(req: Request, repo: Repo): Promise<Response>;
```
